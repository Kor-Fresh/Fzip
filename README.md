# Fzip

## 설명

Fzip은 Windows용 무료 압축 프로그램입니다. 파일과 폴더를 압축하고 다양한 형식의 압축파일을 해제할 수 있습니다.

## 기능

- ZIP · 7z 압축 생성 및 압축 수준 선택
- ZIP · 7z · ALZ · EGG · RAR · ARJ 등 압축 해제
- 압축파일 내부 목록 보기
- 파일과 폴더 드래그 앤 드롭
- 작업 진행 표시, 취소 및 결과 폴더 열기
- 탐색기 우클릭 메뉴에서 압축 및 압축 해제
- Windows 기본 앱 연결과 지퍼 상자 파일 아이콘

## 설치 방법

1. [Releases](https://github.com/Kor-Fresh/Fzip/releases/latest)에서 `Fzip-0.1.1-Setup-x64.exe`를 다운로드합니다.
2. 설치 파일을 실행하고 설치할 위치와 사용할 옵션을 선택합니다.
3. 설치가 완료되면 시작 메뉴 또는 바탕화면에서 Fzip을 실행합니다.
4. 압축파일을 Fzip으로 열려면 앱의 **기본 앱 설정**에서 원하는 확장자를 연결합니다.

Windows x64에서 사용할 수 있으며, 별도의 .NET 설치는 필요하지 않습니다.
